# Licence des assets

Les assets fournis avec ce dépôt (textures, modèles, presets, exemples) sont
licenciés séparément du code. Par défaut, ces assets sont fournis sous la
licence Creative Commons Attribution 4.0 International (CC BY 4.0).

Vous êtes libre de :
- Partager — copier et redistribuer le matériel dans n'importe quel format
  ou support.
- Adapter — remixer, transformer et créer à partir du matériel pour
  n'importe quel usage, y compris commercial.

Conditions :
- Attribution : vous devez créditer l'auteur original, fournir un lien vers
  la licence et indiquer si des modifications ont été apportées. Vous
  pouvez le faire de manière raisonnable, sans suggérer que le donneur de
  licence vous soutient ou soutient votre utilisation.

Texte de licence complet et détails :
- Licence CC BY 4.0 : https://creativecommons.org/licenses/by/4.0/

Exemple d'attribution recommandé :

```
Nom de l'asset — Auteur (Jean-Baptiste BARON / Tech 4 Art Conseil),
Licence CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
```

Si vous préférez une autre licence pour certains assets (par ex. CC0,
CC-BY-SA), merci d'indiquer clairement la licence dans le dossier
concerné (`Presets/`, `TestScenes/`, etc.).
